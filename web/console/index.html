뉴스 한 건을 1080×1080 카드로.

영문 소스(트윗·블로그·아티클)을 한국어 뉴스 카드로 변환하는 파이프라인. 아래에서 소스와 클라이언트를 바꾸면 카드가 실시간으로 다시 그려집니다 — 실제 렌더러가 뽑는 결과의 미리보기입니다.

입력
테마는 클라이언트 브랜드에 매핑 — dark / yellow 슬롯 분기.
NewsCardResult.spec — 렌더러가 받는 슬롯
